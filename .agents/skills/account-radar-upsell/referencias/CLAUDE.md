# Base de Conhecimento — Produtos V4

Catálogo completo de produtos e serviços da V4. Cada produto tem seu próprio arquivo `.md` nesta pasta.

## Como usar
- A skill `account-radar-upsell` lê esta pasta pra recomendar produtos nos radares semanais
- Para adicionar um produto novo: crie um arquivo `{slug-do-produto}.md` seguindo o template `_template-produto.md`
- Mantenha os arquivos atualizados quando o portfólio mudar
